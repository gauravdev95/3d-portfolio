A modern, responsive, and beautifully animated personal portfolio website built using **React**, designed to showcase my projects, skills, experience, and achievements.

## 📦 Installation & Setup

Clone the project:

```bash
git clone https://github.com/gaurav-opensource/portfolio.git
cd portfolio
````

Install dependencies:

```bash
npm install
```

Run the project locally:

```bash
npm start
```

---

## 🚀 Deployment

Recommended platforms:

* **Vercel**
* **Render**
* **Netlify**

Build command:

```bash
npm run build
```
